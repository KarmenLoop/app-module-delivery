# Install and use the skill

## 1. Download

Download the skill ZIP and SHA256SUMS from the [release page](https://github.com/KarmenLoop/app-module-delivery/releases/tag/v1.0.1). Extract the complete app-module-delivery directory. Keep references, templates, scripts, agents, validation, and LICENSE together.

The installable directory is skills/app-module-delivery in a source checkout, or app-module-delivery after extracting the release ZIP.

## 2. Choose a host

The [platform guide](../skills/app-module-delivery/references/platforms.md) is the authoritative setup reference for Codex, Claude Code, Cursor, Qoder, WorkBuddy, Koder, and Koder CLI. It separates documented native paths from actual loading evidence and explains local/cloud differences.

Use one installation source per host and inspect an existing customized copy before replacing it. A file copy does not establish native discovery.

## 3. Invoke

For Codex, explicitly invoke $app-module-delivery after discovery. Claude Code, Cursor, and Qoder document /app-module-delivery. Use the actual client's supported list or selection UI.

Where native discovery is unverified, use a file-capable agent:

~~~text
Read /absolute/path/app-module-delivery/SKILL.md.
Task: add an import module to this application.
Targets: desktop and mobile.
Reuse my requirements and inspect existing identity and storage modules.
First deliver the complete plan and integration impact.
Then continue implementation, operation, repair, and acceptance already authorized.
Preserve unrelated changes and existing QA requirements.
~~~

## 4. Inspect the work

Expect a scope summary, actual capability checks, focused business questions, and a complete application plan before implementation. Existing answers should not be requested again.

After the plan, already-authorized work proceeds by verifiable business increments. The agent explains why an increment is next, operates it, inspects the real result, preserves evidence, and repairs failures.

Use the actual preview/application/command entry. Follow one correlated identifier through input, processing, persistence, and later use. Check permissions and recovery paths. See [verification](verification.md) for evidence boundaries.

## 5. Complete project records

Copy needed [templates](../skills/app-module-delivery/templates/application-plan.md) into your project, fill actual decisions and results, and combine small tables. The [license](../LICENSE) expressly permits completed project records; modified workflow distributions still require permission.
